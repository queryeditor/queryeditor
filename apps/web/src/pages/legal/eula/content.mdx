## 4. Automatic Updates and Network Activity

The Software connects to the internet for the following specific purposes only:

**a) Automatic update checks**
QueryEditor uses `electron-updater` to automatically check for new versions from our public [GitHub Releases](https://github.com/queryeditor) page. The app checks for updates **every 30 minutes** while it is running. When an update is available, the app notifies you and downloads it only upon your confirmation (`autoDownload` is disabled by default). Updates are installed on next restart. You cannot opt out of update checks; however, no personally identifiable information is sent — only your current app version, operating system, and architecture are included in the standard GitHub API request. GitHub's own privacy policy governs how they handle that request.

**b) Your AI provider (optional)**
If you configure an AI API key, the app communicates directly with that provider (OpenAI, Anthropic, or Google) when you use the AI assistant. See the Privacy Policy for full details on what is transmitted.

**c) Your database server**
The app connects to whatever database servers you configure. We have no access to those connections.

The Software makes **no other outbound network connections**. No telemetry, crash reporting, usage analytics, or any other data is transmitted to QueryEditor or its developer.

## 5. Data Storage on Your Device

The Software stores the following data locally on your device:

- **Connection credentials** (hostnames, ports, usernames, passwords, API tokens) — encrypted at rest.
- **Workspace files** (`.sql` query files) — stored as plain text files in a directory of your choosing.
- **Application settings** (editor preferences, AI model selection, theme) — stored in the OS application data directory.
- **AI API keys** (if configured) — stored encrypted in the application data directory.

No data is uploaded to any QueryEditor server. You can delete all application data by uninstalling the Software and removing its application data directory.
