## 3. Connection Safety Modes

QueryEditor provides per-connection safety modes that restrict which queries can be executed. These operate entirely locally via regex-based validation before any query reaches your database:

| Mode | Behavior |
|---|---|
| **Silent** | No restrictions. Full database access. |
| **Read-Only** | Blocks all write operations (INSERT, UPDATE, DELETE, DROP, ALTER, CREATE, etc.). |
| **Safe** | Allows writes but blocks destructive operations without a WHERE clause (e.g., `DELETE FROM` without `WHERE`, `DROP TABLE`). |
| **Confirm** | Shows a native confirmation dialog before every query execution. |
| **Production** | Combines Safe restrictions and Confirm dialog for maximum protection. |

These modes are provided as a convenience tool. They do not replace proper database access controls, backups, or careful review of every query. You remain solely responsible for all queries executed against your databases.
