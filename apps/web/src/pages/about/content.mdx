# About

QueryEditor is a local-first SQL editor for people who prefer to work directly in SQL — no point-and-click table builders, no cloud sync, no account required.

It sits in the same category as tools like Bruno or WarpTerminal: purpose-built for a specific workflow, with a minimal footprint and a considered design.

Currently available for **Windows** in Alpha.

## How It Works

Each database connection gets its own workspace: a directory on your machine where `.sql` files and folders live. You open files as tabs, write queries in the Monaco-based editor, and see results in the data grid — all without leaving the keyboard.

Autocompletion is schema-aware: tables, columns, and databases from your active connection are indexed locally and surfaced as you type.

## Features

- **File-based workspaces** — Queries are `.sql` files on disk. Organize them in folders per connection.
- **Monaco editor** — Syntax highlighting, autocompletion, formatting, and multiple tabs.
- **Schema-aware autocompletion** — Tables, columns, and databases from your active connection.
- **Connection safety modes** — Per-connection rules to prevent accidental writes or destructive queries on sensitive environments.
- **AI assistant** (optional) — Bring your own API key (OpenAI, Anthropic, or Google). The AI reads your schema in read-only mode and requires explicit permission per resource. It cannot execute queries autonomously.
- **Local data grid** — View and explore query results locally. Supports sorting, filtering, and export.
- **No telemetry** — No data is sent to any QueryEditor server. The app works fully offline except for update checks and any AI or database connections you configure.
