## Your File Explorer

The **Primary Sidebar** is located on the left edge of the workspace. It acts as the main navigation hub and file explorer for your active connection.

## Disk-Backed Workspaces

Because QueryEditor links every connection to a physical directory on your local computer, this sidebar displays a real-time tree view of your actual files and folders.

### Core Capabilities

- **Create**: Right-click anywhere in the sidebar to create new `.sql` files or subdirectories.
- **Manage**: Rename, duplicate, or delete files (moving them to your OS Trash) directly from the UI.
- **Native Context**: The sidebar utilizes native OS context menus for file operations, providing a seamless desktop experience.
- **Organize**: Fluidly drag and drop files to move them between folders.

### Real-Time Sync

The sidebar monitors your workspace directory for changes in the background. If you create, edit, or delete a file externally (for example, via your terminal or VS Code), the sidebar updates instantly without requiring a manual refresh.

## Status Header

At the very bottom of the sidebar sits a compact status header that displays:
- Your connection name.
- The active engine (e.g. MySQL, SQLite).
- Connection target details (e.g. host IP or database path).
