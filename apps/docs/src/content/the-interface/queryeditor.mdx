## Where the Magic Happens

The central piece of the application is the **QueryEditor**. This is where you write, modify, and execute your SQL. It is powered by Monaco Editor, bringing a world-class code editing experience directly within the app.

## Editing Features

- **IntelliSense**: Automatic suggestions for SQL keywords, tables, and columns fetched directly from your database schema in real-time.
- **Syntax Highlighting**: Real-time syntax coloring for SQL, making code easier to read, parse, and debug.
- **Block Execution**: If you have multiple queries in the editor separated by empty lines, you can place your cursor inside one block and execute *only* that block, rather than running the entire file.
- **Smart Hovers**: Hovering over tables or columns will display tooltip information derived from the schema (feature currently in development).

## AI Integration

The editor isn't just for typing. Select any block of code and press `Cmd+K` / `Ctrl+K` to open the AI Assistant. When the AI suggests modifications, it applies diffs directly to the text using Monaco's native inline-diff viewer, allowing you to seamlessly Accept or Reject changes without copy-pasting.
