## Staying Up-to-Date, Effortlessly

QueryEditor includes a built-in update system that checks for new releases in the background. Our goal is to ensure you always have access to the latest features, security patches, and fixes without interrupting your workflow.

## The Update Lifecycle

1. **Silent Scanning**: The application periodically checks our servers for new releases in the background.
2. **Manual Check**: If you don't want to wait, head to the Help menu and select **Check for Updates**.
3. **Invisible Download**: If a new version is detected, it downloads automatically in the background.
4. **Quick Installation**: Once the download finishes, a discreet notification will suggest restarting the application to apply the changes.

## Distribution Channels

Because the application is currently in its **Alpha** phase, the updater is configured to pick up and apply pre-release versions, so you always receive the latest improvements as soon as they ship.
