## Global Shortcuts

These commands respond no matter which panel you are currently focused on within the application.

| Action | macOS | Windows / Linux |
|---|---|---|
| Toggle Primary Sidebar | `Cmd+B` | `Ctrl+B` |
| New Query Tab | `Cmd+N` | `Ctrl+N` |
| Save Current File | `Cmd+S` | `Ctrl+S` |
| Save As... | `Cmd+Shift+S` | `Ctrl+Shift+S` |
| Open Settings | `Cmd+,` | `Ctrl+,` |
| Zoom In (Full UI) | `Cmd+=` | `Ctrl+=` |
| Zoom Out (Full UI) | `Cmd+-` | `Ctrl+-` |
| Reset Zoom to 100% | `Cmd+0` | `Ctrl+0` |

## Code Editor Control

These shortcuts activate when your cursor is focused inside the Monaco code editor.

| Action | macOS | Windows / Linux |
|---|---|---|
| Run Query | `Cmd+Enter` | `Ctrl+Enter` |
| Invoke AI Assistant | `Cmd+K` | `Ctrl+K` |
| Find in Code | `Cmd+F` | `Ctrl+F` |
| Find and Replace | `Cmd+Option+F` | `Ctrl+H` |
| Toggle Line Comment | `Cmd+/` | `Ctrl+/` |
| Multi-cursor Selection | `Option+Click` | `Alt+Click` |
| Format SQL Code | `Option+Shift+F` | `Alt+Shift+F` |

## Data Grid Navigation

These actions help you quickly manipulate your query results.

| Action | macOS | Windows / Linux |
|---|---|---|
| Copy Row(s) as JSON | `Cmd+C` | `Ctrl+C` |
| Select Row Range | `Shift+Click` | `Shift+Click` |
| Multi-select Disconnected Rows | `Cmd+Click` | `Ctrl+Click` |
