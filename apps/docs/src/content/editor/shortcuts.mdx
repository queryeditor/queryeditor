## Global shortcuts

These shortcuts work anywhere within the workspace window.

| Shortcut (Mac) | Shortcut (Win/Linux) | Action |
|---|---|---|
| `Cmd + B` | `Ctrl + B` | Toggle Primary Sidebar (Left) |
| `Cmd + N` | `Ctrl + N` | Create a New Query file |
| `Cmd + S` | `Ctrl + S` | Save current file |
| `Cmd + ,` | `Ctrl + ,` | Open Settings |
| `Cmd + =` | `Ctrl + =` | Zoom In |
| `Cmd + -` | `Ctrl + -` | Zoom Out |
| `Cmd + 0` | `Ctrl + 0` | Reset Zoom to 100% |

## Editor shortcuts

These shortcuts apply when your cursor is focused inside the Monaco Editor.

| Shortcut (Mac) | Shortcut (Win/Linux) | Action |
|---|---|---|
| `Cmd + Enter` | `Ctrl + Enter` | Run Query |
| `Cmd + K` | `Ctrl + K` | Open AI Assistant |
| `Cmd + F` | `Ctrl + F` | Find |
| `Cmd + Option + F` | `Ctrl + H` | Find and Replace |
| `Cmd + /` | `Ctrl + /` | Toggle Line Comment |
| `Option + Shift + F` | `Shift + Alt + F` | Format Document |
| `Cmd + D` | `Ctrl + D` | Add Selection to Next Find Match |
| `Alt + Click` | `Alt + Click` | Insert multiple cursors |

## Data Grid shortcuts

| Shortcut (Mac) | Shortcut (Win/Linux) | Action |
|---|---|---|
| `Cmd + C` | `Ctrl + C` | Copy selected row(s) |
| `Shift + Click` | `Shift + Click` | Select a range of rows |
| `Cmd + Click` | `Ctrl + Click` | Select multiple disconnected rows |
