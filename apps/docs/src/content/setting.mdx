## Tuning Your Workspace

The **Settings** window (accessible via the gear icon) is the command center to customize QueryEditor's global behavior. It is neatly organized into four key sections.

## General Preferences

Tweak the aesthetics and base behavior of the application:

- **Visual Appearance**: Force Light mode, Dark mode, or let your System decide.
- **Code Theme**: Change the Monaco editor highlight colors. You can stick to the Default theme or explore alternatives like Ayu or VSCode.
- **Default Workspace**: The root path on your computer where `.sql` files will be saved if a connection lacks a specific folder assignment.
- **Hardware (GPU) Acceleration**: Boost visual performance. If you experience graphical glitches, you can toggle this off (requires app restart).

## Editor Behavior

Tailor the Monaco editor to your coding style:

- **Line Numbers**: Hide or show the numbering gutter.
- **Minimap**: Useful for extremely long scripts, it displays a bird's-eye view of your code on the right side.
- **Word Wrap**: Prevent horizontal scrolling by wrapping long lines automatically into the viewport.
