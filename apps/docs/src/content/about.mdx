## Identity and Version

The **About** window displays system information and the current version of your QueryEditor installation.

## What You'll Find Here

- **Version** — The exact version number you are running (e.g. `0.1.0-alpha.1`). Useful when reporting bugs.
- **Credits and Copyright** — Legal information and links to the official website.
- **Support** — A link to the developer's profile and a donation option if you'd like to contribute to the project.
